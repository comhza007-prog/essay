## 如何复算

PowerShell在本目录执行：

```powershell
& '.\06_复现脚本\reproduce.ps1'
```

默认生成新的 `复算结果_时间戳` 目录，重算18次全部指标、核对源文件哈希，并用Python NumPy独立复核主要误差统计。不会覆盖本次结果。

添加 `-Full` 可再生成Excel、论文图和报告：

```powershell
& '.\06_复现脚本\reproduce.ps1' -Full
```

本机默认使用已安装Codex运行库。第三方库不随包分发：Node分析仅需内置库；Excel需要 `@oai/artifact-tool`，PNG需要 `sharp`；Python验证/PDF需要 `numpy`、`reportlab`。PDF使用Windows宋体TTC并嵌入子集字体。异机需显式传入 `-Node`、`-Python`、`-Modules`、`-ChineseFont`。依赖或字体版本改变后应重新检查生成文档和图的排版。

`manifest.json`保存文件清单、SHA256、固件构建与源文件映射；`SHA256SUMS.txt`也包含manifest本身的校验值。核验清单不自包含自己的哈希。压缩包不含第三方库、编译中间文件或旧准入采集记录。
