# Step 2.5 往复换向基准测试与推力空间同步优先约束分配报告

## 一、研究目标与 2x2 完全因子消融体系

在第二阶段（Step 2）的单程加速工况中，客观数据显示：在执行器严重饱和（$I_{\max} = 4500\text{ counts}$）时，由于左右双侧电机均被独立截断至正向驱动极限（左侧 $+4500\text{ counts}$，右侧 $-4500\text{ counts}$），防偏转力矩 $T_\alpha$ 物理归零，使得 C2b 与 C2a 的最大同步误差完全相同（均为 $0.7734\text{ mm}$）。

为了打破这一饱和同步误差瓶颈，Step 2.5 在二维物理推力空间 $[F_L, F_R]$ 中构建了**同步优先约束分配器 (`thrust_allocator_sync.m`)**，并与动态抗饱和状态 $\mathbf{z}_{\text{aw}}$ 构建了严密的闭环回路。同时，设立 **$2 \times 2$ 完全因子消融矩阵**，在 $7.0\text{ s}$ 往复换向工况（$0 \to 1.0\text{ m} \to 0.0\text{ m}$，含正反向加减速及各 $1.43\text{ s}$ 静止保持）下进行了深入检验：

| 控制器名称 | 动态抗饱和回路 ($\mathbf{z}_{\text{aw}}$) | 执行器控制分配策略 | 控制拓扑结构 |
| :--- | :---: | :---: | :--- |
| **C2a** | 无 (关闭) | 独立截断 | $\mathbf{v}_\beta \xrightarrow{\mathbf{T}_{\text{act}}^{-1}} \mathbf{i}_{\text{request}} \xrightarrow{\mathrm{sat}(\mathbf{I}_{\text{eff}})} \mathbf{i}_{\text{actual}}$ |
| **C2a-SyncAlloc** | 无 (关闭) | 推力空间同步优先分配 | $\mathbf{v}_\beta \xrightarrow{\text{thrust\_allocator\_sync}} \mathbf{i}_{\text{alloc}} \xrightarrow{\mathrm{sat}(\mathbf{I}_{\text{eff}})} \mathbf{i}_{\text{actual}}$ |
| **C2b** | 有 (开启) | 独立截断 | $\mathbf{v}_\beta + \mathbf{T}_{\text{act}}\mathbf{z}_{\text{aw}} \xrightarrow{\mathbf{T}_{\text{act}}^{-1}} \mathbf{i}_{\text{request}} \xrightarrow{\mathrm{sat}(\mathbf{I}_{\text{eff}})} \mathbf{i}_{\text{actual}}$ |

## 四、深入物理分析与客观结论

### 1. 同步优先分配（SyncAlloc）的主效应与客观评价
- **同步误差显著改善 (降幅 62.1%)**：
  在 $I_{\max}=4500$ 强限流工况下，引入推力空间同步优先分配后，无论是 C2a 还是 C2b，最大同步误差均从 $0.7734\text{ mm}$ 降至 **$0.2931\text{ mm}$（降低 62.1%）**。
- **物理机制：优先保留纠偏力矩**：
  该同步精度的改善来自优先保留偏转力矩 $T_\alpha$（可行域内力矩缺额为 $0.0000\text{ N}\cdot\text{m}$，而独立截断 C2a 发生高达 $3.6162\text{ N}\cdot\text{m}$ 的力矩缺额）。
- **性能取舍与局限（不可宣称“全面优于 C2a”）**：
  必须指出，**该改善伴随平动跟踪误差和分配缺额的显著增加**：为保留差动纠偏推力，平动合力 $F_G$ 被主动削减，导致位移跟踪 $\text{RMSE}_{yG}$ 从 $108.9\text{ mm}$ 恶化至 $148.8\text{ mm}$，主动分配缺额积分从 $0$ 增至 $121436.6$。因此客观结论为：**SyncAlloc 在强限流工况下显著改善了同步精度，但牺牲了部分质心轨迹跟踪性能，属于典型的“保同步让平动”工程折中策略**。

### 2. 动态抗饱和回路（$\mathbf{z}_{\text{aw}}$）的主效应
- **抑制控制分配残差累积**：
  对比 C2a-SyncAlloc 与 C2b-SyncAlloc：当分配器为了保力矩而削减推进力时，平动通道产生了巨大的不可实现虚拟力请求（无抗饱和的 C2a-SyncAlloc 主动分配缺额积分高达 $121436.6$）。
  而在 C2b-SyncAlloc 中，闭环残差 $\Delta\mathbf{i}_{\text{alloc}} = \mathbf{i}_{\text{actual}} - \mathbf{i}_{\text{request}}$ 驱动 $\mathbf{z}_{\text{aw}}$ 动态回退未实现虚拟力，将总不可实现残差积分从 $121436.6$ 直接压缩至 **$60777.9$（减幅高达 50.0%）**！
- 相比于传统 C2b，复合后的 C2b-SyncAlloc 控制量总变差 $\text{TV}_{iR}$ 从 $22750.6$ 显著下降至 $16489.6$（动作平滑度大幅提高）。

### 3. 往复过零换向与停靠动态特性
- 在 $0 \sim 3.5\text{ s}$ 正向到达和 $3.5 \sim 7.0\text{ s}$ 反向原点到达时，所有 C2 系列控制器均在 $1.43\text{ s}$ 的静止保持窗口内平稳停靠，超调量均为 **$0.00\text{ mm}$**（未发生过冲），且换向过零过程平稳无冲击。
- 相比之下，工程级联 PID（C0）与传统 CCC（C1）由于位置环动态梯度限幅在低速区的保守性，在正反向停靠时均产生了 $1.41\text{ mm}$ 的拖尾超调。

## 五、学术边界与严谨声明

1. **等效仿真模型边界**：
   本报告所有结论均基于比赛程序参数、机械资料参数和假设等效参数建立的二自由度非线性动力学仿真模型进行的离散数值仿真，不能等同于实车物理实验。
2. **力矩优先保持条件**：
   力矩完整保留的严格前提为：*纠偏力矩请求位于执行器可行域内（即 $|T_{\alpha,\text{des}}| \le \frac{1}{2} L_e (F_{L,\max} + F_{R,\max})$）*。超出该物理可行域时，分配器退化为提供最大可实现极限力矩。
