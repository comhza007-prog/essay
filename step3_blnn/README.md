本目录实现目标论文式（28）至式（34）的宽度学习神经网络（BLNN）结构，并将其接入现有双M3508龙门模型。除无网络、固定RBFNN和原文结构BLNN外，还设置约束感知BLNN（CA-BLNN）作为面向M3508非对称硬限流的开发组。当前版本是可运行原型，不是原论文完整C1复合控制器复现。原有Step 1至Step 4文件不被修改。

## 算法边界

- 已按原文实现的网络结构：两个广义自由度分别建立网络；每个网络输入为 `[qddot, qdot, q, e, edot]`；采用高斯映射节点；采用 `cos(h)`、`sin(h)` 增强节点；执行在线输出权值更新；按照最近节点均值、`tau=0.7` 和 `Theta=0.3` 自动增加节点；初始节点数为4。当前60节点上限是工程设置；原文只报告C1最终节点数为60，未明确把60规定为统一上限。
- 独立参考实现进度：`paper_reproduction/`已接入八参数RLS、平滑饱和精确割线重构、辅助项`v_Xi`、C1–C4结构基线和式（35）轨迹。公式与模块检查通过；合成对象1 ms转角验收尚未通过，Set1–Set3亦未完整重建。详见`paper_reproduction/BATCH_02_RESULTS.md`。本目录原M3508开发基线与参考线保持分离。
- M3508适配部分：使用项目现有电流—推力映射、左右非对称硬限流、动态抗饱和状态和同步优先分配器；使用固定先验尺度对网络输入归一化；设置仅用于防止数值发散的高阈值权值投影。
- 约束感知开发组：当控制请求超出实际电流可行域时，利用分配缺额抑制BLNN继续把“执行器能力不足”学习成“模型不确定性”，防止权值风积。该组不是原论文内容，且当前饱和占比仍未通过最终验收。
- 本模块是数值仿真，不是新增实物实验。原始四组实物实验封档保持不变。

## 文件说明

- `nn_compensator_init.m`：无网络、固定RBFNN和BLNN的确定性初始化。
- `nn_compensator_step.m`：节点增长、增强节点和在线权值更新。
- `controller_c3b_nn_sync_alloc.m`：BLNN、动态抗饱和和SyncAlloc复合控制器。
- `blnn_unknown_disturbance.m`：用于验证估计能力的确定性未建模动态。
- `gantry_dynamics_step_uncertain.m`：带未知广义扰动的RK4仿真对象。
- `run_blnn_benchmark.m`：两种工况、三种网络方案的完整基准测试。
- `verify_blnn.m`：结构、数值安全和性能验收测试。
- `audit/`：开发基线、论文公式追踪矩阵、参数表和复现差距清单。
- `archive/step3_blnn_dev_v0_20261010.zip`：审计前开发基线，只用于回溯。

## 运行方式

在MATLAB中运行：

```matlab
cd('step3_blnn');
run('run_blnn_benchmark.m');
run('verify_blnn.m');
```

或直接运行 `run_step3_blnn.bat`。

输出包括结构化CSV、完整MAT数据、四组PNG/PDF候选图和开发版仿真报告。所有网络中心均采用确定性初始化，因此重复运行不会因随机种子产生不同结论。7/7通过仅代表当前开发版的程序级检查通过，不代表原论文完整复现验收通过。
