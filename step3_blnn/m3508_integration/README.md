## 对比与职责

| 方法 | RLS | CA-BLNN | 动态抗饱和 | SyncAlloc |
| --- | --- | --- | --- | --- |
| Base | 无 | 无 | 有 | 有 |
| RLS | 有 | 无 | 有 | 有 |
| CA-BLNN | 无 | 有 | 有 | 有 |
| RLS+CA-BLNN | 有 | 有 | 有 | 有 |

每种方法共用基础增益、初始名义参数、量化双编码器、因果速度/加速度估计、轨迹、扰动、推力先验和左右限流。工况为标称、偏载/摩擦/增益不确定、停稳阶段载荷阶跃、严重非对称限流，共16组确定性开发仿真。

7秒、0.8 m轨迹用于接续此前的仿真诊断，不是现有10 mm实物轨迹的数值复制。限流为仿真开发设置，不代表立即采用的实物烧录参数。

RLS沿用Step3A的三参数平动估计器，估计质量、黏性摩擦和库仑摩擦的等效值。先验区间在配置中显式拓宽，让四组方法共用原BLNN开发基线的初始名义模型；这属于新试验设置，不改已有RLS成果。偏载时遗漏的耦合项、未知扰动及未校准推力增益可能造成参数偏置，所以必须同时查看参数轨迹、PE激活和回归残差，不能把盒内数值当成真实物理参数收敛证据。

RLS在采样k使用截至k-1的估计，在更新中使用同一时标的上一位置和实际分配后的推力。执行器推力换算统一使用名义先验，不读取仿真真值增益。

BLNN在分配器之前补偿剩余误差。输入来自量化编码器及因果微分链，不读取真实速度/加速度。输出、学习和增点受约束门控；60节点是本项目资源上限。权值投影仍为数值保护，必须记录命中次数。

本批新增方向门控：令基线电流请求为b，网络电流修正为d，选择最大的g∈[0,1]，使每个通道`max(0,abs(b+g*d)-Ieff)`不大于基线的越界量。已越界时只允许朝可行域移动；没有越界时不允许网络推过边界。关闭立即生效、重新开启平滑。学习/增点进一步受基线余量门控。此性质只限制同一状态的一步越界量，不保证整条轨迹的饱和比例、跟踪或同步误差改善，需要动态结果检验。

## 入口

在本目录运行：

```matlab
verify_platform_integration();
report = run_platform_comparison();
```

也可双击`run_platform_comparison.bat`。需要MATLAB和现有SVF类所用的Control System Toolbox。

独立检查覆盖：门控几何可行性及最大性；关闭网络和RLS时与原控制器的电流、抗饱和状态一致；共享初始模型及实际推力接口；非对称限流下的网络接口。程序检查不能替代性能验收。

运行后`results_dev_v1/`生成16行指标CSV、完整MAT时序及四幅PNG。RMSE等指标取0–7 s全程，耗时排除前0.5 s热身。记录跟踪、同步、分配饱和比例、电流到边界比例、分配缺额积分、权值及投影、节点、RLS残差、PE和平均/P95/最大桌面耗时。桌面MATLAB耗时不等于MCU耗时。

新测量链和名义推力先验与旧开发批不同，因此性能判断应在本批共用设置的四组方法间进行，不能直接把新旧CSV之差归因于算法改进。
