# V3 候选冻结与独立验证协议

冻结时点：2026-10-10，24 次分配器/AW 因子诊断之后、独立验证之前。

主候选：CA-BLNN；allocator=clip，两侧各自硬限幅；aw_scale=1；其余保持 integration_config.m 和 options_v2.m 的原值。保留同步误差反馈，不再使用严格词典序同步优先分配。eta=0.01、epsilon=[25,18]、sector_fraction=0.25、60 节点上限均不改。没有用新种子结果调参。

选择依据：旧种子以及确定性诊断中，各自限幅改善强限流下轨迹跟踪；AW 开关不能解释严格优先分配的主要性能损失。加权分配仍作为诊断分支，不增加到主候选。不能将这些选择依据称为独立验证。

独立验证：Uncertainty、Asymmetric limits，每场景 20 对；种子 2026102001–2026102020，与 v2 的 2026101001–2026101020 不同。每对 Base 和 CA 使用相同配置、噪声、延迟、初始条件；两者均 clip/AW1。样本分布沿用 v2：质量±20%、偏心±10%、摩擦变化±20%、力系数±5%、扰动±20%、初始角度±0.1 mrad、2 编码器 LSB 高斯噪声、0–2 ms 延迟。保存全部时序及噪声，不剔除退步试次。

主判断：各场景跟踪 RMSE、同步 RMS 的配对差（CA−Base）95% t 区间上界小于零。次要判断：最大同步误差配对差区间上界不超过 +0.1 mm；绝对终点误差均值不高于 Base+0.1 mm。所有输出有限且满足各场景/固件电流上限。报告全部 20 次，不要求也不冒称每一次都更优。区间为单项区间，未做多重比较控制。若不满足，则如实记录；不修改候选重新称为同一独立测试。

补充完整消融：5 场景×13 方法，统一使用 v3 分配器，唯 Strict SyncAlloc 为分配器单因素回退。固定 4 节点与 RBF60 的容量不同，不能据此单独归因于网络类型。

资源测试是 MATLAB 桌面实现，不等于 MCU 1 kHz 保证。四组实物封档不修改、不据此声称 BLNN 已通过实物验证。稳定性说明须明确工作域及有界残差假设，不作任意强饱和条件下全局收敛宣称。
