# V3 稳定性说明与可宣称范围

本说明针对本项目代码与等效双 M3508 模型，不是对原文定理的照搬。物理参数中的摩擦、推力先验、刚度等仍是假设值。有限时长仿真不能证明全局稳定或模型已完成实物辨识。

## 连续时间理想测量线性骨架

令 q=[y,alpha]'、e=q−qr，M 为实际质量/惯量矩阵，ell=Le/2。实际黏性矩阵为

```
D = [bL+bR, ell*(bR-bL);
     ell*(bR-bL), ell^2*(bL+bR)+Balpha]
K = diag(0,Kalpha)
Ccl = D−Bhat+K1+Mhat*Gamma
Kcl = K−Khat+K1*Gamma
M*e_ddot+Ccl*e_dot+Kcl*e = h
```

h 收集参考前馈失配、库仑摩擦、未知扰动、鲁棒 tanh 项、NN、抗饱和状态、执行器分配残差、增益失配与测量误差。此骨架以名义推力映射组织，增益失配放入 h；不能忽略它。M、Ccl、Kcl 对称正定时，无输入机械线性系统为 Hurwitz；能量导数为 −e_dot'*Ccl*e_dot，再由 LaSalle 排除非零不变状态。

令 x=[e;e_dot]，A=[0,I;−M\Kcl,−M\Ccl]，B=[0;M\I]。若 h 在所声明工作域有界，||h||≤H，取 A'P+PA=−I、V=x'Px：

```
Vdot <= −0.5*||x||^2+2*||P*B||^2*H^2
     <= −V/(2*lambda_max(P))+2*||P*B||^2*H^2
limsup ||x|| <= 2*sqrt(lambda_max(P)/lambda_min(P))*||P*B||*H
```

这是条件性 ISS/UUB 结论，不是任意饱和下的全局跟踪定理。质量阶跃时须分段处理；有限个跳变可用两段 P 的特征值比控制 V 跳变，不能直接写同一个 P 对所有参数均成立。平移米与角度弧度混合范数需要固定坐标尺度，不应拿该保守界直接代替论文的毫米性能指标。

## 代码对应的采样/测量线性骨架

`theory_check_v3.m` 另构造含 50 Hz 速度滤波与 0/1/2 ms 位置延迟的增广离散模型，真实推力增益直接进入输入矩阵。状态为真实 q/v、延迟位置队列、上一步速度滤波值。控制线性项为 Q*qm+V*vf，Q=Khat−K1*Gamma、V=Bhat−K1−Mhat*Gamma。采用连续物理线性模型的精确零阶保持离散化；**不是 RK4 非线性整环的精确离散化**。

每个固定参数/固定延迟模型检查 rho(Phi)<1 以及 Phi'*Pd*Phi−Pd=−I。对增广系统 X_next=Phi*X+f，若扰动 f 有界，则

```
Delta V <= −0.5*||X||^2+C*||f||^2
C = ||Pd||+2*||Phi'*Pd||^2
```

因此固定模型对有界外部残差具有 ISS 性质。检查范围为 6 个确定性参数配置（载荷阶跃前后单独列出）及 40 个独立验证样本，各 3 种固定延迟，共 138 个矩阵。逐个稳定不能证明任意时变切换稳定，也不能证明连续参数盒内所有模型稳定。

## 有界性与不等式：哪些成立，哪些仍是条件

- 网络输出按通道限为 [80 N,10 Nm]；节点每通道最多 60；权值逐分量投影有界。冻结误差梯度仍保留泄漏，不意味权值辨识真实扰动收敛。
- 纠偏保护对**测量误差面**逐时刻保证 sigma_i*nuNN_i≤0.25*K1_ii*sigma_i^2；方向门控保证网络不增加当时基础请求的越界量。这两条不是全闭环稳定性证明，也不能保证全程饱和比例一定降低。
- 鲁棒增益限制于 K2_min/K2_max，tanh 有界。参考轨迹有界。
- AW 欧拉更新 z_next=0.98*z+0.016*aw_scale*delta_i。若每通道 |delta_i|≤Di，则 |z_k|≤0.98^k|z0|+0.8*aw_scale*Di*(1−0.98^k)。**实际电流限幅不等于请求/缺额有界**；未经证明不能用这一假设反过来宣称任意强饱和系统全局稳定。
- 未知力中含 v*|v|，仅在明确速度工作域内有界。高斯噪声也没有全时域确定性幅值上界；保存样本的有限时长有界不代表未来任意噪声序列有界。
- 需要有界测量误差、请求/分配残差与工作域，才能把非线性项作为有界输入使用以上 ISS 结论。本批仿真只检验有限运行中的数值及约束，没有证明该域正向不变。

论文可表述为“约束感知 BLNN 的有界实现、局部/工作域条件性稳定性分析，以及含量化、延迟和不确定性工况的数值验证”。不可写“任意载荷/饱和下全局渐近收敛”“完整继承原文定理”或“已由四组实物验证 BLNN”。若论文必须以无条件全局稳定为创新点，本批不能完成该要求，需要另行设计并证明可行域/不变集。
