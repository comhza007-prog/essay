# CA-BLNN v2 方法与验证协议

日期：2026-10-10。该版本是本平台工程改进，不是原论文完整C1控制器，也不是可直接烧录的固件。

## 不变项与来源

沿用 `integration_config.m` 的1 ms控制周期、7 s/0.8 m往返轨迹、量化编码器与因果微分链、名义模型、基础增益、推力映射、动态抗饱和和同步优先分配。旧 `results_dev_v1`、旧控制器和四组实物封档不改动。恢复诊断已逐点验证Base和旧CA的状态、电流与dev_v1一致。

counts是CAN电流命令单位，不是安培；位移m、偏角rad、广义补偿分别为N和N·m。推力系数、摩擦和抗扭参数包含原工程模型的假设值，仿真不能证明其已在实物标定。恢复批与消融批使用相同工况，新增对称限流仅作为额外诊断。

## 新增纠偏保护

令网络原始广义补偿为 `v_NN=-d_hat`，误差面为 `sigma=edot+Gamma*e`。每个通道的允许正功率为：

```text
budget_i = kappa * K1_ii * sigma_i^2,  kappa = 0.25
sector_i = 1                              if sigma_i*v_NN_i <= budget_i
sector_i = budget_i/(sigma_i*v_NN_i)       otherwise
```

仅限制抵消基础纠偏的那部分补偿，不限制有助于纠偏的负功率补偿。随后执行原方向可行域门控与立即关闭、30 ms平滑重新开启。采用公共输出系数g∈[0,1]，最终补偿为 `g*sector_i*v_NN_i`。

这保证每步 `sigma_i*v_NN_applied_i <= kappa*K1_ii*sigma_i^2`，因此网络不会在此内积中抵消超过25%的 `-K1*sigma` 阻尼。代码逐步断言此不等式。此性质不保证跟踪误差单调，也不是完整闭环稳定性定理。它是本文新加的保护，必须与原文结构和旧CA门控区分。

## 学习与节点增长

旧版本的学习系数同时关闭误差驱动和泄漏；新版本学习系数只控制误差驱动：

```text
w_next = project(w + Ts*epsilon*(learning_gate*sigma*feature - eta*w))
```

误差学习冻结时保留泄漏，防止旧权值永久保持。增点系数单独传入，可独立消融。原4节点、20 ms增点间隔、60节点工程上限和补偿限幅保持不变。新增只读预测避免每步执行两次完整学习器；零权值新节点不改变当步预测，接口检查验证了这一点。

## 验证批次

- 恢复诊断：4工况×5设置，共20组。Base、旧CA、只改泄漏、只加纠偏保护、完整v2。旧CA重现检查不是用新基线替换旧结果。
- 消融：5工况×13方法，共65组。包括独立RLS、固定RBF60、无门控BLNN、完整v2、逐个去掉纠偏/输出/学习/增点门控、固定4节点、去掉增强层、去掉SyncAlloc、RLS组合。
- 鲁棒性：参数不确定性和非对称限流各20次配对样本；每样本Base与v2各运行一次，共80组。种子2026101001–2026101020，每场景都使用同一组种子。质量±20%、偏心距±10%、摩擦变化幅度±20%、左右增益各±5%、附加扰动幅度±20%；初始偏角±0.1 mrad；双轨位移噪声标准差2个编码器LSB；延迟0–2 ms。以上噪声是验证假设，不是实物噪声测量。保存每个样本及共享噪声，绝不为不同控制器重新抽样。
- 敏感性：两个关键工况，7参数×3水平，共42组。kappa={0.1,0.25,0.5}，Theta={0.2,0.3,0.5}，tau={0.5,0.7,0.9}，width={0.7,1,1.3}，节点上限={30,60,90}，泄漏率和学习率分别为默认值的{0.5,1,2}倍。逐项扫描，其余固定；不依据结果重新选择“最优”参数。

主指标为全程跟踪RMSE、同步RMS/峰值、末端误差与6.5–7 s尾段RMSE。分开报告分配缺额发生比例和实际电流到边界比例；前者下降不代表后者必然下降。统计使用配对差值v2−Base及20样本、19自由度的双侧95% t置信区间；均值区间不证明所有未来样本都改善。

## 理论与部署边界

投影保证每个权值分量不超过30/15；60节点时每通道3n特征，`||feature||<=sqrt(2n)`，补偿另有80 N/10 N·m限幅。这只证明网络资源和输出有界。方向门控保证同状态的瞬时不可实现量不增加；纠偏保护保证上述内积上界。

若抗饱和输入缺额已知有界，离散状态满足 `z_next=0.98*z+0.016*deficit`，可得到其条件有界性；不能反过来假设缺额有界并宣布完整闭环已证明。仍需在本平台质量矩阵、参数误差、耦合、测量误差和分配残差下补完整闭环推导。旧论文定理不可直接套用。

两个网络最大静态数值存储约1080个标量（中心、宽度、三类权值）：double约8640 B，single约4320 B，不含对象开销、临时数组、观测器、通信及堆栈。MATLAB仍使用动态增点数组；MCU版必须固定上限预分配，并实测目标板周期。桌面计时、并行批计时均不能作为MCU实时验收。
